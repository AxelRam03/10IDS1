# 10IDS1 — Aplicación web con Vue y Vuetify

Repositorio de trabajo que contiene un proyecto frontend basado en Vue 3, Vuetify y Vite, junto con una copia comprimida de los materiales del proyecto.

## Tecnologías identificadas
- Vue 3 y Vuetify 3
- Vite
- TypeScript
- Vue Router y Pinia
- ESLint y vue-tsc para calidad y comprobación de tipos
- jsPDF y Axios como dependencias del proyecto

## Requisitos
- Node.js compatible con las dependencias del proyecto
- npm

## Ejecutar localmente
Desde la carpeta del proyecto:

```bash
cd 10IDS1V_A-master
npm install
npm run dev
```

## Comprobaciones disponibles
```bash
npm run type-check
npm run build
```

Antes de publicar, verifica que el proyecto compile correctamente y que no se hayan incluido credenciales, datos personales ni archivos de configuración locales.
